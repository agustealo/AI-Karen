# AI KAREN runtime dependencies
# Keep this file aligned to live imports/runtime composition. Do not retain retired backends "just in case".
#
# Persistence / memory dependency policy:
# - PostgreSQL/Supabase is the canonical durable memory substrate.
# - SQLAlchemy is the canonical ORM/session/engine abstraction used by PostgresEngine and durable repositories.
# - psycopg/psycopg2 are PostgreSQL drivers used by sync/runtime paths where configured.
# - asyncpg is required by the canonical SQLAlchemy async URL (postgresql+asyncpg://).
# - redis is an active runtime dependency for bounded STM/session/hot-context storage through platform/memory/redis.
# - pgvector, pg_trgm, pg_cron, pgTAP, recursive CTE traversal, and RLS are PostgreSQL/Supabase
#   capabilities/extensions and therefore are NOT Python packages to add here.
# - Do not add NetworkX, pgmq clients, Neo4j, Memgraph, FalkorDB, Graphiti, Mem0, Apache AGE
#   clients, or another graph/vector database dependency without a benchmark-backed ADR.
# - Existing KAREN spreading activation must be integrated and benchmarked before considering
#   an external graph-compute library.
# - A graph accelerator, if ever approved, is derived compute/projection only; it never becomes
#   authoritative durable memory.
#
# Retired backends/dependencies include: neo4j, kuzu, duckdb, hnswlib.
# Redis and SQLAlchemy are NOT retired. Deprecated Redis import shims must converge on
# ai_karen_engine.platform.memory.redis, while SQLAlchemy consumers must converge on the
# canonical ai_karen_engine.persistence.postgres.PostgresEngine/session path.
